# Smart Unit Converter

A multi-category Unit Converter built with HTML, CSS, and JavaScript. Convert values between different units using a simple, interactive interface.

## Features

- **Length Conversion:** Meter, Kilometer, Centimeter, Millimeter, Foot, and Inch
- **Time Conversion:** Second, Minute, Hour, and Day
- **Weight Conversion:** Milligram, Gram, Kilogram, and Ton
- **Data Conversion:** Bit, Byte, Kilobyte, Megabyte, and Gigabyte
- **Temperature Conversion:** Celsius, Fahrenheit, and Kelvin
- Interactive unit selection and conversion controls

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Select a conversion category.
4. Choose the source and target units.
5. Enter a value and click the Convert button.

## Project Purpose

This project was created to practice JavaScript DOM manipulation, event handling, objects, and mathematical conversion logic.
